## 描述（4000）

```
练账是一个只做一件事的健身 App：把每一组训练记准，然后告诉你下一次该练多重。

【为什么还需要一个训练 App】
大多数健身 App 在卖课程，练账在算账。
课程哪里都能看，但你练过的 80 公斤、9 次、RPE 8——这些数据只在这里。

【核心功能】
· 双进阶配重：次数做满上限才加重，连续两次没达标才减重，不会瞎猜
· 组间休息自动计时：锁屏和灵动岛上就能看到剩余时间
· 容量分析：胸背腿肩手臂核心，每周有效组对照目标区间
· 周报：训练次数、完成率、总容量、PR、下一次该补哪块肌群
· 减脂期力量保持率：阶段内最佳 1RM ÷ 阶段前最佳 1RM，告诉你掉的是脂肪还是肌肉
· Apple Watch：手表上看当前动作，点一下就能完成本组

【和数据有关的三件事】
1. 不设账号，不联网也能用，训练数据只存在你自己的手机上。
2. 每次训练结束自动备份，最多保留 3 份；也可以随时导出完整 JSON 或 CSV。
3. 换手机时用「从备份恢复」把数据带过去。

【适合谁】
每周练 3 次以上、想看到数字变化的人。如果你只是想跟着视频动一动，练账可能不是最适合你的。

【不适合谁】
练账不提供医疗建议、康复方案或极端减重计划。有伤病请先就医。

训练记录永久免费。Pro 为一次性买断，解锁配重建议、进阶分析与力量保持率。
```

## 审核备注（App Review Information）

```
本 App 不需要登录，也没有服务器。首次启动会进入 5 问建档，回答后即可开始训练。
所有训练数据保存在设备本地（SwiftData），不上传。

内购测试：
- Pro 买断：com.trainledger.app.pro.lifetime
- 计划包（3 个非消耗型）：com.trainledger.pack.strength5x5 / .cutkeep / .home20

HealthKit：仅读取体重与体脂率用于图表，不写入、不上传。
Live Activity：训练开始后出现在锁屏与灵动岛，结束训练即消失。
```
