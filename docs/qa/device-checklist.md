# 真机走查清单

模拟器给不了的答案都在这里。按 A→Q 顺序走，一轮约 60 分钟；时间紧就只跑最后一段「10 分钟冒烟」。

## 0. 准备

- 设备：一台 iPhone（iOS 17+），一台 Apple Watch（可选），一台 iPad（可选）
- 数据：用 Xcode 启动参数 `-demoData` 写入 4 周演示数据；正式走查前用「我的 → 删除所有训练记录」清空
- 账号：沙盒测试账号（TestFlight 或 Xcode 里的 StoreKit Configuration）

## A. 首次启动与建档

| 检查项 | 通过标准 |
| --- | --- |
| 首启进入 5 问引导 | 不闪屏、不白屏，第一步 1 秒内出现 |
| 选「家里有哑铃」 | 最终计划是「居家哑铃」，动作列表里没有杠铃动作 |
| 选「刚开始 + 每周 4 次」 | 计划仍为「全身」，不是上下肢 |
| 跳过建档 | 直接进今天页，默认 PPL、每周 3 练，不崩溃 |
| 二次启动 | 不再出现引导 |

## B. 记录流程

| 检查项 | 通过标准 |
| --- | --- |
| 开始训练 | 复合动作自动带 1 组热身，热身重量约为建议重量的 50% |
| 输入重量 | 数字键盘能弹出，`kg` 单位不遮挡输入框 |
| 完成一组 | 勾选后立刻开始休息倒计时，按钮变绿 |
| 休息结束 | 归零后自动隐藏休息条，不重复计时 |
| 加一组 | 新组复制上一组重量与次数 |
| 返回 | 未完成的训练保留，再进今天页显示「继续上次训练」 |
| 完成训练 | 记录落到历史，今天页出现「上次训练」卡片 |

## C. 配重建议

| 检查项 | 通过标准 |
| --- | --- |
| 首次练某动作 | 显示「待校准」，不瞎给重量 |
| 上次 12 次 RPE 8 | 今天建议 +2.5kg |
| 上次 12 次 RPE 9.5 | 今天建议保持 |
| 连续两次没到次数下限 | 今天建议 −2.5kg |
| 建议理由 | 点开能看到具体数值依据，不是空泛文案 |

## D. 周报与容量

| 检查项 | 通过标准 |
| --- | --- |
| 有 4 周数据 | 完成率、总容量、PR 数都非零且合理 |
| 切换「近 7 天 / 前 7 天」 | 数字随之变化，不串数据 |
| 肌群条 | 六个肌群都有值，颜色区分不足/达标/过量 |
| 空数据 | 显示引导文案，不显示 NaN 或 0% |

## E. 减脂期力量保持率

| 检查项 | 通过标准 |
| --- | --- |
| 阶段为减脂 | 今天页出现「力量保持率」卡片，可点进详情 |
| 有阶段前后数据 | 分项显示百分比与「阶段前 → 现在」的重量 |
| 缺数据 | 显示「无数据」，并给出补齐建议 |
| 切换阶段 | phaseStartedAt 被重置为当天，百分比重新计算 |

## F. 深色模式（逐屏）

在控制中心切到深色，逐屏确认：

- [ ] 今天 / 记录 / 周报 / 我的 四个 Tab
- [ ] 训练中（含休息条，应为深底白字，不是白底白字）
- [ ] 建档引导（选中态数字块）
- [ ] 阶段与保持率
- [ ] 计划包
- [ ] 买断页
- 通过标准：无白底白字、无黑底黑字；卡片与背景有可辨边界；强调色上的文字清晰

## G. Dynamic Type

设置 → 显示与亮度 → 文字大小调到最大（含「更大辅助功能字号」）：

- [ ] 今天页的动作行不截断成半行
- [ ] 训练中的组行不横向溢出（重量/次数/RPE 不重叠）
- [ ] 周报的三个数字块不挤成两行
- [ ] 建档引导的选项文案不被裁掉

## H. VoiceOver

- [ ] 组的完成按钮读「第 3 组，点按标记完成」
- [ ] 容量条读「胸，每周 8 个有效组，目标 10 到 20 组，不足」
- [ ] 设置齿轮读「设置」，不是「按钮」

## 需要真机标定阈值的地方

动作评估里的四个阈值是按经验给的，必须用真实视频校准后再对外宣称准确：

| 常量 | 当前值 | 说明 |
| --- | --- | --- |
| `SquatAnalyzer.bottomThreshold` | 110° | 判定「进入下蹲」的膝角 |
| `SquatAnalyzer.lockoutThreshold` | 160° | 判定「回到站立」的膝角 |
| `SquatAnalyzer.depthTarget` | 100° | 提示深度不足的门槛 |
| `SquatAnalyzer.torsoLimit` | 45° | 提示前倾过多的门槛 |

标定方法：找 3 个人各拍 3 条视频，人工数次数与肉眼判断深度，与 App 结果对比，误差超过 1 次或 10° 就调。

## 10 分钟冒烟（每次发版前）

1. 清空数据 → 建档 → 开始训练 → 记 3 组 → 完成训练
2. 看今天页「上次训练」与「周报」数字是否对得上
3. 锁屏确认实时活动出现与消失
4. 切深色模式，看今天页与训练中
5. 导出 JSON → 删除所有记录 → 从备份恢复 → 确认条数一致
